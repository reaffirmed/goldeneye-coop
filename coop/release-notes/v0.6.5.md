Co-op fix release of GoldenEye 007 story co-op, built on Project Midas 1.0.2b.

**Works with v0.5.0 to v0.6.4.** The co-op protocol version stays at 14, so v0.6.5 players can still play with anyone on v0.5.x or v0.6.x. The fix runs on the joiner's game, so joiners should update. Players on v0.6.4, v0.6.3, v0.6.2, v0.6.1, v0.6.0, v0.5.x, v0.4.0 or v0.3.0 get the update from the game itself: the top of the CO-OP screen's PLAY tab shows "Update to v0.6.5 - Install". Players on v0.4.0 or older must update to play with v0.5.x or later. Players on v0.2.1 or older have no updater and need this zip from GitHub. Every player needs their own GoldenEye 007 (USA) cart image in the `Data` folder; the image is not included. See `README-COOP.txt` inside the zip.

## Fixed

- **Running guards no longer look choppy on the joiner.** Each guard was placed on the host's smooth path and then moved again by the uneven steps of its own run animation, so running guards lurched back and forth every frame at any frame rate. Now only the host's path moves the guard, and the animation moves just its body and legs.

## Known issues

- The game still keeps its saves and updates in its own folder, so it needs a folder you can write to (not Program Files).
