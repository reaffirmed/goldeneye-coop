Menu and guard AI release of GoldenEye 007 story co-op, built on Project Midas 1.0.2b.

**Works with v0.5.0 and v0.5.1.** The co-op protocol version stays at 14, so v0.5.2, v0.5.1 and v0.5.0 players can still play together. Updating is optional, but recommended for anyone who hosts with Smarter guards. Players on v0.5.1, v0.5.0, v0.4.0 or v0.3.0 get the update from the game itself: the top of the CO-OP screen's PLAY tab shows "Update to v0.5.2 - Install". Players on v0.4.0 or older must update to play with v0.5.x. Players on v0.2.1 or older have no updater and need this zip from GitHub. Every player needs their own GoldenEye 007 (USA) cart image in the `Data` folder; the image is not included. See `README-COOP.txt` inside the zip.

## New

- **Classic co-op menu.** A new **Co-op Menu: Modern / Classic** option, on Port Options and on the CO-OP screen's OPTIONS tab, switches at once. Classic shows the co-op rows on the original folder's paper as one list, with the photo strip of the next mission, the PREVIOUS tab and the paper-coloured character select. Every co-op option is reachable from either look.
- **All Options from the CO-OP screen.** The CONTROLS tab is now **OPTIONS** and ends with **All Options**, which opens the whole Options folder (video, audio, HUD, accessibility, key binds and Port Options) while the lobby keeps running. PREVIOUS takes you back. If the host starts a mission while you are in there, you still follow them in.

## Clearer CO-OP screen

- **Tab and Shift+Tab change tab** on the keyboard, and the tab bar shows a TAB key. The `,` and `.` keys still work (before, their keys showed up blank), and pads keep LB and RB.
- Before you host, GAME SETUP says that the mission rules appear once you host.
- A host who is alone is told where to invite friends from, and Select Mission and Start Match say "No Players" instead of "Not Ready".
- **Guards** is renamed **Guard Strength**, so it isn't mixed up with Guard AI or the mission difficulty, and its help now says what Hard and Brutal do.
- **Check Now** is renamed **Game Version**. It shows your version, and selecting it asks GitHub for updates.

## Smarter guard fixes

These only matter when the host picks **Smarter** guard AI.

- **Guards now find bodies.** The check almost never ran, so guards walked past fallen comrades. Now a nearby guard notices a body, walks over, searches the area and goes back to post.
- **One look per body.** A guard no longer walks back out to the same body every time it returns to its post.
- **Searches happen.** Guards that were meant to search an area used to head straight home.
- **The guards stay the same after a host change.** If the host left, the guards switched to whatever the new host had set, usually Classic. They now keep the AI the mission started with. This needs the player who takes over to be on v0.5.2.

## Known issues

- Smarter guards only hide from the player they are fighting, so with 3 or 4 players another player may still see them in cover.
- A guard running for an alarm picks it by straight-line distance, not by how far it has to walk.
- After a host change, Smarter guards start their current move over rather than carrying on exactly where they were.
- The game still keeps its saves and updates in its own folder, so it needs a folder you can write to (not Program Files).
